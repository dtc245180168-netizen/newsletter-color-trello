# [Bài Tập] Phối Màu Cho Newsletter (Trello Sample)

Dự án thực hành phối màu sắc giao diện Newsletter mẫu của Trello sử dụng Bootstrap 5 và các quy tắc phối màu trên công cụ Adobe Color.

## 🎨 So Sánh 2 Bộ Màu Lựa Chọn Từ Adobe Color

### 1. Phiên bản 1: Trello Tech Productivity (Ocean Blue & Vibrant Coral)
- **Quy tắc phối màu:** **Complementary (Màu bổ túc)**
- **Màu chủ đạo (Primary):** `#0079BF` (Màu xanh dương đặc trưng của Trello - thể hiện sự tập trung, chuyên nghiệp và đáng tin cậy)
- **Màu phụ (Secondary):** `#026AA7` (Xanh đại dương đậm dùng cho header/footer tạo chiều sâu)
- **Màu điểm nhấn (Accent):** `#FF7A00` (Cam rực rỡ nằm đối xứng trên Color Wheel, tạo sự thu hút thị giác mạnh mẽ cho các ưu đãi, badge)
- **Màu nền sáng (Light BG):** `#F4F5F7` (Xám nhạt dịu mắt, tăng độ tương phản cho thẻ nội dung)
- **Màu chữ chính (Text):** `#172B4D` (Xanh than sẫm, độ tương phản đạt chuẩn WCAG AAA trên nền trắng)

### 2. Phiên bản 2: Creative Royal Purple & Warm Amber (Sáng Tạo & Sang Trọng)
- **Quy tắc phối màu:** **Split Complementary / Triad (Bổ túc kép)**
- **Màu chủ đạo (Primary):** `#7B2CBF` (Tím hoàng gia - khơi nguồn cảm hứng, sáng tạo và tư duy đột phá)
- **Màu phụ (Secondary):** `#3C096C` (Tím thẫm huyền bí cho header/footer)
- **Màu điểm nhấn (Accent):** `#FF9E00` (Vàng hổ phách ấm áp tạo cảm giác cao cấp và năng động)
- **Màu nền sáng (Light BG):** `#FAF5FF` (Sắc tím oải hương cực nhạt tạo bầu không khí nghệ thuật)
- **Màu chữ chính (Text):** `#10002B` (Tím đen tuyền đảm bảo độ sắc nét khi đọc)

## 📁 Cấu Trúc Thư Mục Dự Án

```

├── index.html                  # Trang tổng quan có bộ chuyển đổi Live Switcher giữa 2 phiên bản
├── newsletter_version1.html    # Phiên bản 1 (Ocean Blue & Coral)
├── style1.css                  # CSS tùy chỉnh với CSS variables cho Phiên bản 1
├── newsletter_version2.html    # Phiên bản 2 (Royal Purple & Warm Amber)
├── style2.css                  # CSS tùy chỉnh với CSS variables cho Phiên bản 2
├── comparison.html             # Trang so sánh 2 phiên bản song song
```

## 🚀 Hướng Dẫn Chạy & Nộp Bài

1. Mở file `index.html` trên trình duyệt để trải nghiệm bộ chuyển đổi trực tiếp giữa 2 bộ màu.
2. Mở trực tiếp `newsletter_version1.html` hoặc `newsletter_version2.html` để xem từng phiên bản độc lập.
3. Dự án đã được khởi tạo Git sẵn sàng để đẩy lên GitHub.
